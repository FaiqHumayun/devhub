# DevHub - Developer Community Platform

## Overview
DevHub is a full-stack MERN + Next.js (TypeScript) application where developers connect, share projects, write posts, and follow each other.

## Features
- Authentication (NextAuth)
- User profiles
- Developer posts
- Project showcase
- Follow system
- Notifications
- Admin dashboard

## Tech Stack
- Next.js + Tailwind CSS + TypeScript
- Node.js + Express.js
- MongoDB + Mongoose
- NextAuth.js
- Cloudinary (uploads)

## Getting Started
```bash
git clone https://github.com/yourusername/devhub.git
cd devhub
pnpm install
pnpm dev
